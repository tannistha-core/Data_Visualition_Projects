# Python Data Visualization Project Using Seaborn

## 📌 About

This project explores different real-world datasets using **Python, Pandas, Matplotlib and Seaborn**. The aim is to perform basic data analysis and represent findings through suitable visualizations.

## 🛠️ Tools Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Google Colab

## 📊 Datasets & Tasks

### 🚢 1. Titanic Survival Analysis

Analysed passenger survival based on **gender, passenger class, age and fare**.
Created visualizations such as countplots, barplots, histograms, scatterplots and boxplots.

### 🍽️ 2. Tips Dataset Analysis

Analysed **total bills, tips, days, time, gender and smoking status** to understand customer tipping behaviour.
Used scatterplots, boxplots, violinplots and barplots.

### 🐧 3. Penguin Species Analysis

Compared different penguin species based on **body mass, flipper length, sex and other numerical features**.
Used countplots, boxplots, violinplots, scatterplots and pairplots.

### 🌸 4. Iris Flower Dataset

Explored the differences between flower species using **sepal length, sepal width, petal length and petal width**.
Used boxplots, violinplots, heatmaps, countplots and pairplots.

### 🎓 5. Student Performance Analysis

Analysed student **math, reading and writing scores** and investigated factors such as gender, parental education and test preparation.
Created boxplots, barplots, histograms and correlation heatmaps.

## 📈 Skills Demonstrated

* Dataset loading and exploration
* Data cleaning and missing-value analysis
* Pandas data analysis
* Data visualization using Seaborn
* Statistical summaries
* Correlation analysis
* Interpreting graphs and identifying patterns
